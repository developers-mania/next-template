# Next Template

A Next.js 16 + Redux Toolkit starter for client-side apps that talk to a separate backend.

The app lives in [`next-app/`](next-app). See its [README](next-app/README.md) for the project structure, conventions and how to connect your backend.

```bash
cd next-app
npm install
npm run dev
```

Set `NEXT_PUBLIC_API_URL` in `next-app/.env.local` to your backend, then open [http://localhost:3000](http://localhost:3000).
